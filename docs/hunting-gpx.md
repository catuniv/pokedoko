# 자동사냥 GPX

`/gpx`는 체육관 레이드와 별도로 자동사냥에 사용할 좌표 경로를 다룬다. 기존 `/live`의 지역 선택은 체육관 목록 확인 기능으로 유지하며, GPX는 전용 화면에서 선택한다.

## 경로 입력

- 공개 GPX: [원본 출처 문서](hunting-route-sources.md)의 8개 파일을 사용자가 선택하면 브라우저가 고정 리비전의 원본 호스트에서 직접 요청한다. GPX 원문·좌표는 서비스 저장소에 포함하지 않는다. 선택한 카드 바로 아래에 설정과 미리보기를 표시한다.
- 포켓스톱: `/api/gpx/stops?city=tokyo&spot=0&radius=3`처럼 저장소에 등록된 도시·추천 장소·반경만 요청한다. PoGo Radar 공개 `quests` 계층의 포켓스톱 표본이며 전체 포켓스톱이나 현재 포켓몬을 뜻하지 않는다. 자료가 없는 지역은 빈 결과를 명시한다.
- 내 파일: GPX 또는 `위도,경도` 줄바꿈을 현재 탭에서만 읽으며 서버에 업로드하지 않는다. 파일2MiB, 원본20,000점, 내보내기50,000점 한도를 둔다. DTD/ENTITY, 잘못된 좌표, 분리된 여러 트랙을 거부하고 앞 공백·단일 구간의 legacy `wpt`를 지원한다.

## 속도와 경로 설정

사용자가 제시한 걷기9.3km/h, 순회15km/h, 빠른 순회20km/h를 빠른 선택으로 제공한다. 이 값은 PolygonX의 검증된 공식 한계나 포획·부화 성공 기준이라는 뜻이 아니다. km/h와 m/s는1m/s=3.6km/h로 환산하며, 일반 입력 범위0.1~120km/h는 이 도구의 형식 제한이다.

거리와 예상 이동 시간은 구면거리/설정 속도로 계산하며 정차·게임 플레이 시간을 포함하지 않는다. 원본 순서를 유지하고, 출발점 연결 또는 왕복을 명시적으로 선택할 수 있다. 열린 원본의 반복은 시작점으로 점프하지 않도록 거부한다. 경로는1~20회 반복하며, 포켓스톱 자동 경로는 중심에서 가까운 실제 포켓스톱 최대20·50·100·200곳을 골라 제한된 순환 정렬을 수행한다. 전역 최단 경로나 실제 보행 도로를 보장하지 않는다.

GPX는 선택한 `trk` 또는 `rte` 하나만 내보내 중복 경로를 만들지 않는다. 예정 시각은 기본적으로 넣지 않고 사용자가 선택한 경우에만 계산한다. 메타데이터에 계획 경로임과 속도·반복·원문 출처를 표시한다. GPX를 가져오는 앱이 시각을 사용하지 않으면 앱 자체의 속도 설정을 적용하므로 PolygonX에서도 원하는 속도를 직접 설정해야 한다.

## 수집과 실패 처리

포켓스톱 요청은 고정 HTTPS 원본으로만 나가며4초 대기,2MiB,800개 한도를 둔다. 성공 결과는 최대5분, 실패는30초 재사용한다. 생성 시각이10분을 넘긴 원문은 새 자료로 표시하지 않으며 캐시가 원문 유효기간을 연장하지 않는다. 동시 요청 합치기와5초 요청 임대·세대 검증으로 중단된 요청이 이후 결과를 막거나 덮어쓰지 않게 한다.

원본 GPX를 불러오지 못하면 해당 카드에 오류를 표시하고 원문 다운로드 후 내 파일로 가져올 수 있게 안내한다. 경로·도시·원본·파일을 바꾸면 이전 비동기 응답과 이전 내보내기를 취소한다. 개인 파일은 링크로 공유하지 않으며 공개 원본·포켓스톱 검색 조건·속도 설정만 URL로 공유한다.

## 검증

`tests/hunting-route.test.mjs`는 실제 경로 순서·반복 경계·시간·GPX 형식·정밀도·파싱 제한, `tests/hunting-stops.test.mjs`는 공개 포켓스톱 분류·검증·캐시·요청 제한·정렬, `tests/hunting-settings.test.mjs`는 URL 복원·개인 입력 제외·원본 출처 메타데이터를 검증한다.
