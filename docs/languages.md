# 언어 선택

한국어(`ko`), 영어(`en`), 중국어 간체(`zh-CN`), 일본어(`ja`)를 화면 상단에서 고른다. 기본값은 한국어이며, 선택한 값은 브라우저의 `pokedoko.language.v1`에 보관한다. 저장이 차단되어도 현재 화면에서 언어를 바꿀 수 있다. 다른 탭의 변경도 반영하고 `html.lang`을 갱신한다.

## 번역 범위

`lib/i18n-messages.json`, `lib/i18n-extra-messages.json`, `lib/i18n-page-messages.json`에는 메뉴·일정·레이드·GPX·루트·교환 양식과 오류 안내·개인정보 안내의 확인된 화면 문구를 세 언어로 보존한다. 새 문구에 번역이 없으면 원문으로 표시하며 외부 번역 API에 보내지 않는다. 이용자 게시글·닉네임·임의 루트 이름·연락 방법·좌표·GPX·원문 기사 내용은 자동 번역하지 않는다. 배경의 실제 이름과 출처 정보도 임의로 바꾸지 않는다.

도시·국가 이름을 번역하며 검색은 기존 한국어·영어와 현재 표시 언어를 함께 사용한다. 포켓몬의 한국어 이름은 확인된 공식 명칭 데이터로 영어·중국어 간체·일본어에 대응한다. 교환 화면의 영어 종 이름은 식별용으로 유지하고, 사용자 지정 이름이나 원문을 다른 포켓몬으로 추정하지 않는다.

## 구현과 보존

`LanguageProvider`와 `useLanguage`가 선택 상태와 번역 함수를 제공한다. `LanguageScope`는 React 요소의 텍스트와 접근성 레이블을 번역한다. DOM 노드나 브라우저 번역 기능을 조작하지 않는다. 입력값·선택값·ID·URL·좌표·키·이벤트 처리기는 바꾸지 않는다. `value`를 생략한 HTML option도 원래 값을 유지한다.

`data-i18n-preserve` 또는 `translate="no"`가 있는 요소는 내용 그대로 표시한다. 사용자 입력을 포함하는 새 화면에도 이 표시를 적용한다. 서버 오류는 등록된 안내 문구만 번역하며 알 수 없는 오류를 다른 뜻으로 추정하지 않는다.

시간 계산과 데이터 원본은 바꾸지 않는다. 달력과 시계 표시는 선택 언어의 `Intl.DateTimeFormat`을 사용하되 서비스의 한국시간(KST)·도시별 현지 시간 구분을 유지한다.

검증은 `tests/i18n.test.mjs`에서 언어별 기본 문구·명칭·기기 저장 실패·사용자 내용 보존·입력값과 option 값 보존을 확인한다. 모바일 화면과 실제 페이지의 선택·검색·저장 동작은 별도로 확인한다.
