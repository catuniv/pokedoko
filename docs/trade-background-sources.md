# 교환 포켓몬 배경 선택 근거

확인일: 2026-11-10. `lib/trade-backgrounds.ts`의 목록은 공식 공지에서 확인한 배경의 **입력용 제안 목록**이다. 전체 배경 도감이나 포켓몬별 획득 가능 배경 표가 아니다. 저장하는 이름은 이벤트·장소를 구분하기 위한 pokedoko 표기이며, 게임 내부 배경 ID 또는 공식 에셋 이름이라고 주장하지 않는다.

## 참고한 PogoTrades 동작

- [공개 교환 목록](https://pogotrades.com/world-storage): All / Shiny / Shadow / Background Only / Costume Only 필터, 포켓몬별 카드와 상세 보기.
- [공개 교환 목록 생성기·설명](https://pogotrades.com/blog/pokemon-go-trade-list-generator): 원하는 포켓몬과 제공할 포켓몬을 나누고, 색이 다른 모습·코스튬·배경 변형을 선택하는 흐름을 확인했다.
- 로그인 없이 볼 수 있는 페이지의 기능 구분만 참고했다. 비공개 등록 화면이나 계정 기능을 확인했다고 표현하지 않는다. 타 사이트 코드·이미지·회원 게시글·연락처를 가져오지 않는다.

## 배경 종류

[공식 Special Backgrounds 소개](https://pokemongo.com/news/special-backgrounds?hl=en)는 Location Background와 Special Background를 구분한다. 두 배경 모두 포켓몬 요약 화면에 나타나는 기념 배경이다. 사이트 카드의 장식용 바탕색과 다르다.

공식 공지의 본문 또는 실제 이미지에서 확인되지 않은 배경을 만들어 등록하지 않는다. 설명용 표시명과 공식 에셋 이름을 구분하며, 내부 ID·이미지·색상 코드를 만들어 넣지 않는다. 포켓몬과 배경의 조합은 작성자 입력 정보이므로 선택 자체가 실제 소유, 게임 내 획득 가능 여부 또는 교환 가능 여부를 검증하지 않는다. 목록에 없는 배경은 사용자가 이름을 직접 입력할 수 있고, 운영자가 모집 글을 검토한다.

기존 게시글에 배경 정보가 없으면 `배경 미지정`이다. 이를 `배경 없음`으로 바꾸어 표시하지 않는다. 요청 포켓몬의 `배경 종류 무관 · 배경 있는 포켓몬`은 배경이 있는 포켓몬을 원하되 종류를 가리지 않는 모집 조건이며 실제 배경 종류가 아니다.

과거 GO Fest Osaka·Paris 공식 행사 페이지는 현재 404, Jersey City 페이지는 배경 설명 없는 행사 공지로 이동했다. 해당 과거 도시 배경의 존재를 부정하는 것이 아니라 이번 공식 출처 확인 범위의 한계다. 이 선택지는 공식 근거를 다시 확보할 때까지 제안 목록에 자동 추가하지 않으며, 작성자가 직접 입력할 수 있다.

## 배경 이미지 미리보기

`public/trade-backgrounds`의 원본 이미지와 SHA-256·파일 크기·출처는 `lib/trade-background-image-manifest.json`에 기록한다. 기존 17개 선택지에는 PokeMiners의 `Images/LocationCards` 공개 원본을 사용하며 원본 커밋 `db10df75d6f6f92018d9786af0aecc238fecc4ef`에 고정했다. PNG 바이트를 바꾸지 않고 포켓몬의 투명 아트워크와 별개 레이어로 표시한다. 일부 스페셜 배경은 게임에서 효과를 덧입히는 기본 정지 텍스처여서 애니메이션·추가 효과까지 재현했다고 표시하지 않는다.

2026 와일드에리어 글로벌 배경은 [공식 공지](https://pokemongo.com/en/news/get-ready-for-gowildarea-2026)와 [Into the Wild 공지](https://pokemongo.com/en/news/into-the-wild-2026)에서 확인했다. 현재 미리보기는 [LeekDuck의 공개 안내 이미지](https://cdn.leekduck.com/assets/img/events/article-images/2026/2026-11-09-into-the-wild-2026/into-the-wild-special-background.webp)의 오른쪽 배경 카드 부분을 CSS로 표시한다. 원본은 수정하지 않았으며 별도 포켓몬이 없는 오른쪽 패널만 보이도록 한다. 이 자료를 게임의 독립 배경 PNG라고 주장하지 않는다.

배경 이름과 종류가 일치할 때만 이미지를 연결한다. 사용자 직접 입력이 알려진 배경과 일치하지 않거나 이미지 로딩이 실패하면 상태를 표시하며 다른 배경을 임의로 넣지 않는다. 배경 미지정·배경 없음·원하는 배경 종류 무관에는 실제 특정 배경 이미지를 지정하지 않는다.

향후 배경 목록·이미지의 공개 자료 자동 갱신, 원본 갱신일과 조회 시각의 구분은 [자동 배경 갱신 문서](trade-background-updates.md)를 따른다. 이 자료는 커뮤니티 카탈로그이며 모든 항목이 공식 검증을 마쳤다는 의미가 아니다.
