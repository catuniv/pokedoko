## 붙여 넣을 소개문

포고 일정이랑 레이드 한곳에서 보려고 pokedoko 만들어봤습니다.

이벤트 달력, 등장 포켓몬, 도시별 레이드아워를 한국시간으로 볼 수 있고, 지원 도시의 실제 레이드와 반경별 레이드 밀집 지역도 확인할 수 있어요. 좌표는 바로 복사됩니다. 모바일 지원하고 로그인 없이 무료로 쓸 수 있습니다.
지역을 고르면 종료 시간과 이동 조건을 반영한 레이드 방문 경로를 만들고 GPX로 복사하거나 내려받을 수도 있어요.

사이트: 위 표에서 게시할 채널의 링크를 선택하세요.

써보시고 오류나 필요한 기능 있으면 사이트의 ‘의견 보내기’로 알려주세요. 유용하셨다면 GitHub Star도 부탁드립니다: https://github.com/catuniv/pokedoko

## 처음 2주에 확인할 것

첫 목표를 실사용자 약20명의 피드백을 받는 것으로 잡는다. 이 숫자는 운영 목표 예시이며 이미 확보한 이용자 수가 아니다. 기능을 써본 사람에게 다음 행사에도 다시 쓰는지, 첫 화면에서 무엇이 막혔는지 물어본다. 변경한 점을 공개하고 동일 글을 여러 곳에 반복 도배하지 않는다.

유입 수와 함께 공유·좌표 복사·7일 재방문을 본다. 익명 브라우저 기준 지표의 한계와 확인 SQL은 [growth-operations.md](growth-operations.md)에 있다. Google Search Console·네이버 검색 도구 등록은 해당 소유자 계정에서 진행해야 하며, 사이트맵 제공만으로 등록·검색 순위가 보장되지는 않는다.
