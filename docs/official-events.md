한국을 포함하는 글로벌 행사다. 모든 시작·종료 값은 `kind: "local"`이며 선택 도시의 IANA 시간대로 계산한다. 같은 날짜라도 키리티마티(UTC+14)와 호놀룰루(UTC-10)의 실제 시작 시각은 24시간 차이 난다. 화이트·블랙큐레무는 도감 번호 646을 공유하지만 `form: "white"`와 `form: "black"`으로 구별한다.

화이트·블랙큐레무 일정은 와일드 에리어의 일별 레이드 목록이지 레이드 아워나 별도 큐레무 레이드 데이가 아니다. 일반 레이드 목록은 티켓 전용 항목과 분리되어 있고, 티켓 전용 리서치와 추가 보너스는 별도로 안내한다. 무한다이맥스는 배틀 후 포획할 수 없고 일반 무한다이노의 GO패스 보상도 기존 포획 여부에 제한이 있다. 자망칼의 주 이벤트 종료 17시와 일부 보너스 종료 21시를 구분한다. 픽시의 현지 레이드 데이 시간과 별도의 PST 기준 리모트 상한 보너스 시간을 섞지 않는다.

## 중복과 갱신

같은 이벤트 ID는 공식 정보로 덮어쓴다. ID가 달라도 같은 공식 공지 URL과 같은 현지 시작·종료 슬롯이면 공식 정보 하나로 정리한다. 공식 사이트의 언어 경로·추적 쿼리·마지막 슬래시 차이는 동일 원문으로 취급한다. 주말 전체 행사와 토요일·일요일 세부 행사는 서로 다른 슬롯이므로 함께 남긴다. 무관한 행사와 원본 입력 배열은 변경하지 않는다.

종료된 일정은 달력 기록으로 보존할 수 있다. 현재·다음 이벤트 선택은 화면에서 실제 종료 시각으로 판단해야 한다. 행사 종료 후 다음 확정 이벤트로 이동하는 기능과 새 공지를 수집하는 기능은 구분한다. 아직 공지되지 않은 이후 일정은 생성하지 않으며, 화이트큐레무의 매주 반복·작년 행사 날짜 재사용·임의 레이드 지속 시간은 추가하지 않는다. 공식 공지가 변경되면 원문을 다시 확인하고 이 목록과 검증 테스트를 갱신한다.

공식 보완 일정의 포켓몬은 확인한 실제 이미지14개를 `public/pokemon`에 저장했다. 메가픽시·화이트/블랙큐레무·무한다이맥스는 정확한 폼 자산을 사용한다. 새 일반 포켓몬은 도감 번호로 대체 이미지를 조회하고, 알려지지 않은 폼은 일반 모습으로 대신 표시하지 않는다. 모든 이미지 조회가 실패하면 이름과 이미지 미등록 안내가 남는다. 출처와 폼 번호는 [pokemon-artwork.md](./pokemon-artwork.md)에 기록했다.
