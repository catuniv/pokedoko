# 교환 배경 목록 자동 갱신

확인일: 2026-11-10.

## 현재 목록

직접 확인한 기본 배경은 `lib/trade-backgrounds.ts`에 보존한다. 배경 원본과 이미지 확인 범위는 [배경 출처](trade-background-sources.md)를 따른다. 2026 와일드에리어 글로벌 스페셜 배경은 [공식 배경 공지](https://pokemongo.com/en/news/get-ready-for-gowildarea-2026)와 [Into the Wild 2026 공지](https://pokemongo.com/en/news/into-the-wild-2026)에서 존재를 확인했다. 센다이·멕시코시티 지역 배경과 글로벌 스페셜 배경을 구분하며, 2025년 배경을 2026년 이미지로 표시하지 않는다.

## 자동 갱신 공급원

- 공개 목록: [psoren/pogo-bg](https://github.com/psoren/pogo-bg).
- 실제 JSON: `https://raw.githubusercontent.com/psoren/pogo-bg/main/docs/data/data.json`.
- 원본에서 날짜가 확인되는 지역·스페셜 배경의 이름·분류·이미지 경로만 사용한다. `first`가 미래 날짜이거나 날짜가 불명확한 항목은 자동 목록에 넣지 않는다.
- 확인 시 공개 원본은 422,000바이트, `generated: 2026-08-31`이었다. 날짜 검증을 통과한 237개 항목에 기본 18개를 병합한 결과는 255개였다. 공급원 변경에 따라 수치는 달라질 수 있다.
- 자동 목록은 커뮤니티가 정리한 자료다. 모든 항목이 Pokémon GO 공식 API에서 제공되거나 서비스가 자체 검증한 공식 정보라고 표시하지 않는다. 화면의 자료 출처에서 확인할 수 있다.
- 자동 이미지 경로는 같은 공개 저장소의 `docs/img/bg/[안전한 파일명].jpg`만 허용한다. 외부 입력으로 임의 URL을 조회하는 프록시를 제공하지 않는다. 이미지는 선택된 항목에서만 불러오며, 다른 사이트의 코드를 복사하거나 이미지 폴더 전체를 내려받지 않는다.
- 직접 확인해 보관한 로컬 원본은 로컬 파일을 우선 사용한다. 자동 목록의 외부 이미지를 불러오지 못하면 이미지 미확인으로 표시하고 포켓몬 이름·교환 조건은 유지한다.

이 공급원은 Pokémon GO 운영사의 공식 API가 아니다. 공급원이 새 배경을 게시하면 다음 갱신에서 가져올 수 있지만, 공급원이 갱신을 멈추거나 경로·형식을 바꾸면 자동 추가가 지연될 수 있다. 확인하지 않은 배경을 출시됐다고 만들어 넣지 않는다. 파일의 현재 조회 시각 `fetchedAt`과 원본 자체의 갱신 날짜 `sourceUpdatedAt`을 구분한다.

## 갱신과 장애 처리

- 조회 API는 읽기 전용 `GET /api/trade-backgrounds`다. 업로드·승인·임의 URL 입력 API는 없다.
- 기존 Cloudflare `SCHEDULE_CACHE` KV 또는 `BUCKET` R2에 고정 키 `pokedoko/trades/background-catalog-v1.json`으로 정상 목록만 저장한다. 기존 일정 저장 키·통계·사용자 교환 글을 수정하지 않는다.
- 서버 조회는 정상 목록을 6시간 재사용한다. 기존 매일 `0 0 * * *`(UTC, 한국시간 오전 9시) 예약 작업은 목록을 강제로 다시 확인하고 정상 결과를 저장한다. 예약 작업은 일정 갱신·자료 보관 정리와 독립적으로 시작한다.
- 웹 화면은 처음 열릴 때와 30분마다, 화면으로 돌아왔을 때 갱신 시기가 됐으면 API를 다시 확인한다. 사용자가 선택한 배경·직접 입력한 이름·작성 중인 교환 글을 갱신 때문에 초기화하지 않는다.
- 고정 HTTPS 원본 요청은 최대 5초, 최대 4MiB다. 리디렉션을 따라가지 않고 실패 처리하며 실제 스트림 크기도 검사한다.
- 원본 요청에 실패하면 마지막 정상 목록·기존 조회 시각을 유지하고 `stale: true`와 안내를 반환한다. 마지막 정상 목록이 없을 때는 기본 목록을 사용한다. 실패 응답으로 KV/R2 정상 자료를 덮어쓰지 않는다.
- KV/R2 기록 실패도 예약 작업에서 실패로 기록한다. 원본 응답 전문·연락처·관리 키 같은 내용을 오류 로그에 넣지 않고 상태·개수·자료 시각만 남긴다.

## 외부 자료 고지

커뮤니티 목록은 Serebii·Dittobase 등을 정리한 [pogo-bg의 출처 안내](https://github.com/psoren/pogo-bg)를 따른다. 이미지·Pokémon 명칭의 권리는 원래 권리자에게 있다. 공개 파일 조회가 포괄적인 자유 재배포·상업 이용 허락이라는 뜻은 아니다. 기존 비공식 팬 도구 고지와 무료·광고 없는 운영 기준을 유지한다. 자세한 권리 구분은 [외부 자료 고지](../THIRD_PARTY_NOTICES.md)를 따른다.
