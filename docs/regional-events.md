# 지역 한정 이벤트

`/regional`은 나라·도시마다 다른 코스튬과 로케이션 배경을 확인하는 화면이다. 최초 목록은 2026-11-10에 공식 공지와 대조한 14곳이며 사용자 글이나 개발용 예시 보상을 섞지 않는다. 행사 운영·지정 지점·보상 변경은 원문을 확인한다. 이 상세 보상 목록은 검증한 자료이며, 배경 선택 카탈로그의 자동 갱신을 모든 지역 행사 공지의 자동 검증이라고 표현하지 않는다.

## 행사 사실 근거

- [APAC 교차지역 GO Stamp Rally](https://pokemongo.com/news/event-apac-stamp-rally-2026): 쿠알라룸푸르·타이베이·싱가포르·마닐라의 장기 도장 보상과 해당 장소를 확인했다. 2026-09-12~2029-09-11이며 도시별 스탬프 보상과 단기 5개 도장 랠리·야생 출현을 구분한다. 방콕 장소·시작일은 미발표여서 임의로 추가하지 않았다.
- 코스튬 색상: [쿠알라룸푸르](https://pokemongo.com/news/event-kuala-lumpur-30th-anniversary-2026)는 청록색, [타이베이](https://pokemongo.com/news/event-taipei-30th-anniversary-2026)는 분홍색, [싱가포르](https://pokemongo.com/news/event-singapore-30th-anniversary-2026)는 파란색, [마닐라 공식 Pokémon 안내](https://ph.portal-pokemon.com/30th/topics/20260707_01/)는 빨간색이다. 의상 색상을 색이 다른 포켓몬 확정 보상으로 표시하지 않는다.
- [ESA 박물관 행사](https://pokemongo.com/news/european-space-agency-event): 2026-10-04~2027-04-30, 박물관 6곳에서 현장 1성 레이드의 우주비행사 피카츄를 확인했다. 배경 확률 수치는 공개되지 않아 `unknown`으로 표시한다. 뮌헨 본관 대신 뉘른베르크 지점을 쓴다. 일반 야생 증가·필드리서치는 10월 10일에 끝났고 ESA 사무소 7곳은 배경 대상에서 제외되어 현재 보상으로 추가하지 않는다. 박물관 운영·입장 가능 시간을 날짜 범위에서 추정하지 않는다.
- [센다이·멕시코시티 지속 도장 랠리](https://pokemongo.com/news/forever-stamp-rally-go-wild-area-2026): 지역별 8개 도장 보상으로 센다이 배경 라프라스·멕시코시티 배경 루차불을 확인했다. 시작은 2026-11-03T00:00:00Z이므로 멕시코 현지 날짜는 11월 2일, 센다이는 11월 3일이다. 종료일 미정은 24시간 영구 운영 보증이 아니다.
- [Night Out 공식 공지](https://pokemongo.com/news/pokemon-night-out-irl-details2026): LA는 2026-10-24, 런던은 2026-11-10이다. 피카츄 1성·팬텀 3성 현장 레이드의 도시 배경 보상으로, 의상은 발표되지 않아 일반 모습을 사용한다. 정확한 게임 운영시간은 임의 생성하지 않는다. [사용자가 제시한 DC 글](https://gall.dcinside.com/mgallery/board/view/?id=pokemongoplus&no=239600&search_head=90&page=1)은 실제 브라우저에서 제목과 두 좌표를 확인했다. 글 제목의 11/10을 LA 행사 날짜로 옮기지 않는다.

## 사진과 좌표

배경 12개·정확한 코스튬 5개의 원본 PNG는 PokeMiners 커밋 `db10df75d6f6f92018d9786af0aecc238fecc4ef`에서 확인했다. 원본 바이트·해시·크기·출처는 `lib/regional-assets.json`에 있다. 센다이·멕시코시티 배경은 기존에 확인한 로컬 원본을 재사용한다. 일반 라프라스·루차불·피카츄·팬텀 4개도 같은 커밋의 Pokémon GO 게임 스프라이트 원본(256×256)을 검증해 로컬에 저장했다. 총 21개 원본을 사용하며 최초 이미지 표시가 외부 이미지 서버 응답에 의존하지 않는다. 다른 행사 배경이나 일반종 이미지를 미확인 코스튬 대신 넣지 않는다.

`lib/regional-events-data.ts`의 각 장소에는 좌표 출처가 있다. 타이베이는 공식 관광 자료, 나머지는 OpenStreetMap 기여자·Wikidata·사용자 제시 글과 공식 행사 장소를 대조했다. 좌표는 공개 장소 **참고점**이며 실제 보상 포켓스톱·체육관 좌표를 확인한 것은 아니다. 소수점 원문 정밀도와 공백 없는 `위도,경도` 복사를 유지한다. 잘못 검색된 쿠알라룸푸르·타이베이 동명 장소는 폐기했다. 마닐라는 쇼핑몰 참고점이며 옥상 MOA Sky의 정확한 스탬프 좌표로 표시하지 않는다.

## 시간과 화면

기간 상태는 각 장소의 IANA 시간대와 달력 날짜를 기준으로 `기간 중 / 예정 / 종료`로 계산한다. 기간 중은 실제 현재 레이드·포켓몬 출현 확인이라는 뜻이 아니다. 종료일은 현지 날짜의 마지막 날까지 포함하고, 명시된 전 세계 시작 instant는 현지 날짜와 함께 적용한다. 날짜만 발표된 자료에 시작·종료 시각이나 매일 운영 시간을 만들지 않는다.

4개 언어에서 국가·기간 필터와 포켓몬/의상 검색을 제공한다. 획득 방법·참여 조건·공식 링크는 각 카드 바로 안에서 펼쳐진다. 실패한 사진은 미확보 상태를 표시하고, 좌표 복사가 막히면 기존 직접 복사 입력을 제공한다.
