# 지가르데 셀 루트 계획

`/routes`는 상단의 **공개 커뮤니티 루트 목록·제보**와 하단의 **개인 GPX 방문 계획**으로 구성한다. 커뮤니티 제보는 서버 D1에 비공개 접수하고 운영자가 게임 정체성·권리를 검토한 후 게시한다. [제보·검토 운영 문서](community-routes.md)를 따른다. 이 문서의 나머지 내용은 브라우저에만 저장하는 개인 도구를 설명한다.

실제 게임 루트 geometry를 자동 수집하는 공개 공급자는 연결하지 않았다. 임의 GPX·레이드 순회 경로를 승인된 Pokémon GO 루트로 표시하거나 셀 획득을 보장하지 않는다.

## 공식 확인 근거

- [공식 2026년 10월 게임플레이 업데이트](https://pokemongo.com/en/news/pgo-gameplay-update-oct-2026): 발견한 셀은 루트 완료 시 보상으로 자동 지급되며 지도에서 누를 필요가 없다. 발견 확률은 바뀌지 않아 모든 루트에서 받지는 않는다.
- [현재 Routes FAQ](https://scopelyexplore.helpshift.com/hc/en/5-pokemon-go/faq/1220-routes-faq/): 셀이 지도에 표시되지 않고 자동 수집됨을 재확인한다. 일일 셀 상한은 이벤트·규칙 변경 가능성과 현재 1차 문서 범위를 고려해 하드코딩하지 않았다.
- [공식 루트 안내](https://scopelyexplore.helpshift.com/hc/en/5-pokemon-go/faq/1216-what-are-routes/): 게임 Nearby 메뉴 또는 Campfire에서 승인된 루트를 찾고, 실제 시작점에서 Pokémon GO의 Follow를 선택해야 한다. Campfire에서 보는 것만으로 시작되지 않는다.
- [공식 루트 소개](https://pokemongo.com/routes): 경로 기록·검토·승인 절차가 있다.

PogoMap은 [공개 커뮤니티 루트 지도](https://www.pogomap.info/route-map/)를 제공하지만, 조사 중 서울·도쿄·뉴욕을 포함한 재사용 가능한 공식 루트 ID+경로 geometry 공개 공급자/API와 사용 범위를 검증하지 못했다. 일반 hotspot GPX 저장소는 게임의 게시 루트 데이터가 아니므로 초기 경로 목록을 채우는 데 사용하지 않는다.

## 입력·보관

- 사용자가 이름과 도시를 지정한 GPX 또는 `위도,경도` 줄 목록만 등록한다. 원문 HTTPS 링크와 역방향 허용 여부는 사용자가 직접 확인해 입력한다. 모든 항목에 **게임 루트 미검증**을 표시한다.
- GPX는 브라우저 DOMParser로 파싱한다. 1MiB 초과, DOCTYPE/ENTITY, parsererror, 잘못된 좌표, 선택 geometry 2,000점 초과를 거부한다.
- GPX에 같은 경로의 trk와 rte가 함께 있으면 trk를 우선한다. trk가 없을 때 rte를 사용한다. 한 파일에 연결되지 않은 여러 track segment/route가 있으면 나눠 등록하도록 안내한다.
- 연속해서 완전히 같은 좌표만 합치며 비연속 반복과 원래 점 순서는 보존한다. 등록 한도는 20개다. 각 저장 카드의 개별 GPX 내보내기는 경로 한 개를 원래 정방향으로 보관하므로 다른 기기에서 다시 등록할 수 있다. 여러 경로가 들어 있는 방문 계획 GPX는 별도 표시하며 일괄 재등록은 지원하지 않는다.
- 비동기 파일 읽기는 요청 번호와 수동 입력 변경으로 오래된 완료 결과를 무시한다.
- `pokedoko.cell-routes.v1` localStorage만 사용한다. 좌표·GPX·셀 기록을 서버나 통계로 전송하지 않는다. 저장본 읽기 실패/잘못된 기록이 있으면 그 세션의 쓰기를 막아 원본을 보존하고 GPX 내보내기 및 저장본 다시 읽기를 안내한다. 저장 실패 역시 성공으로 표시하지 않는다.

## 계획·내보내기

최대 3개 또는 5개의 등록 경로를 선택한다. 가능한 첫 경로·허용된 방향별로 시작한 뒤 다음 경로 거리와 연결 직선거리를 비교하는 제한된 탐욕 휴리스틱이다. 전역 최단 경로나 실제 도보 길을 보장하지 않는다. 각 경로 길이는 한 번 계산해 재사용한다.

역방향은 명시적으로 체크한 경로에만 적용한다. 원본 점을 재정렬하지 않는다. 게임 루트 사이 이동은 직선거리로 표시하고 GPX에는 만들어 넣지 않는다. 각 경로를 별도 trk 또는 rte로 내보내며, 빈 계획은 내보내기 버튼을 표시하지 않는다. 좌표는 지수 표기 없이 직렬화하고 GPX의 경도180은 같은 위치인 -180으로 정규화한다. XML1.0 제어 문자는 제거하고 이름의 특수 문자는 escape한다. 출발/도착 시간은 생성하지 않는다.

거리·시간은 등록 경로 길이와 구간 사이 직선거리 합 및 시속4.5km를 기준으로 한 추정이다. 대기와 게임 플레이 시간은 포함하지 않는다. 경로도는 동일 축척의 좌표 도식이며 도로 지도가 아니다.

## 수동 완료 기록

도시의 IANA 시간대 기준 날짜로 완료 여부·받은 셀 수를 직접 기록한다. 오늘 완료 제외는 선택 사항이며 게임과 동기화되지 않는다. 셀 입력0~999는 레코드 형식 한도이지 게임의 일일 상한이 아니다. 게임 완료/셀 획득은 서버에서 검증하지 않는다.

단위 검증: `tests/cell-routes.test.mjs`. 브라우저 DOMParser 실제 XML 동작·파일 읽기 경쟁·기기 보관/수동 기록·내보내기는 통합 브라우저 QA에서 추가 확인한다.
