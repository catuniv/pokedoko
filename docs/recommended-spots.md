# 추천 스팟과 좌표

레이드아워 화면에서 도시를 선택하면 하단에 해당 지역의 추천 스팟을 표시합니다. 2026-11-10에 공개 이용자 추천 글, 지역 포켓몬 GO 커뮤니티 안내와 직접 플레이한 가이드를 확인해 24개 도시 112곳을 정리했습니다.

대부분의 도시는 5곳씩 제공합니다. 홍콩과 나이로비는 추천 원문·좌표 근거를 함께 확인한 3곳, 키리티마티는 추천이 집중된 런던 마을의 1곳만 표시합니다. 같은 구역을 인위적으로 나누거나 일반 관광지를 채워 넣지 않았습니다.

각 장소의 `sourceUrl`은 추천 근거, `coordinateSource`는 좌표 근거입니다. 목록의 ‘추천 근거’에는 실제 이용자 글 외에도 지역 커뮤니티·공식 커뮤니티 모임 안내가 포함됩니다. 원자료와 확인 메모는 [recommended-spots-sources.json](recommended-spots-sources.json)에 보존합니다.

좌표는 공원·역·광장·쇼핑 구역을 가리키는 대표점이며 개별 체육관이나 현재 로비 인원·밀집도를 보장하지 않습니다. 과거 이용자의 둥지·출현 기록은 현재 등장 포켓몬 정보로 사용하지 않습니다. 현재 게임 구성과 이벤트 운영은 달라질 수 있습니다.

지도 좌표는 Wikidata P625, Wikipedia, 공식 장소 지도·지역 지도와 공개 이용자 좌표를 확인했습니다. OpenStreetMap을 근거로 한 장소는 해당 링크를 함께 표시합니다. 원문 숫자를 유지하며 복사값은 `위도,경도` 형식입니다. 공백·괄호·추가 안내 문구를 클립보드 값에 넣지 않습니다.

추천 글과 좌표 근거는 화면에서 직접 열 수 있습니다. 목록에 나오는 좌표 복사와 실시간 레이드 카드의 좌표 복사는 동일한 버튼을 사용합니다.
