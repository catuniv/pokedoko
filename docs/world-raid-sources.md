# 세계 실시간 레이드 공급원

2026-11-10 공개 페이지·브라우저용 JavaScript·실제 JSON 응답을 조사했습니다. [조사 메타데이터](world-raid-source-audit.json)에 확인 시각과 통합 API의 도시별 결과를 보존했습니다. 고정 예시 레이드를 운영 데이터에 넣지 않습니다.

## 연결한 자료

| 공급원 | 범위 | 실제 조회 |
| --- | --- | --- |
| [PoGo Radar](https://pokecoords.iflowgo.com/) | 세계 대표24개 도시의 중심 반경15km | `/iflowgopokecoords/api/v1/nearby`의 `layers=raids`, `limit=800` |
| [NYCPokeMap](https://www.nycpokemap.com/gym.html) | 뉴욕 지도 범위 | 공개 `raids.php` |
| [SydneyPogoMap](https://www.sydneypogomap.com/gym.html) | 시드니 지도 범위 | 공개 `raids.php` |
| [SGPokeMap](https://sgpokemap.com/gym.html) | 싱가포르 지도 범위 | 공개 `raids.php` |
| [LondonPogoMap](https://londonpogomap.com/gym.html) | 런던 지도 범위 | 공개 `raids.php` |

PoGo Radar 공개 UI가 허용하는 반경1~15km·100/300/500/800개 중 최대값을 사용합니다. 서울은 다른 시각의 두 응답에서 실제 목록 변화와 한국어 체육관명을 확인했고, 도쿄·홍콩·타이베이에서도 좌표·보스·시작/종료 시각을 확인했습니다. 통합 API 최초 검증에서는 서울·도쿄를 포함한15개 도시에 레코드가 있었습니다. 이 값은 당시 결과이며 계속 변합니다.

24개 도시는 서울·도쿄·타이베이·홍콩·싱가포르·방콕·두바이·시드니·퍼스·오클랜드·키리티마티·이스탄불·런던·파리·마드리드·뉴욕·시카고·로스앤젤레스·호놀룰루·밴쿠버·멕시코시티·상파울루·케이프타운·나이로비입니다. 모든 국가 전체를 스캔한다고 설명하지 않습니다. 빈 응답만으로 그 도시의 실제 레이드가0개이거나 공급원이 해당 도시를 완전히 수집한다고 판단하지 않습니다.

## 정확도와 인원

- 상한800개에 도달한 도시에는 ‘상한 도달’을 표시합니다. 반경15km 안 전체가 아닌 가까운 일부 자료일 수 있어 밀집도도 수집된 표본 기준입니다.
- `generated_at`과 지역 지도의 `meta.time`은 응답 생성 시각입니다. 체육관별 마지막 관측 시각이 아닙니다.
- 보스·시작/종료·좌표를 원문대로 쓰고, 같은 도시·좌표6자리 식별자·시작시각의 중복 공급원을 한 번만 셉니다. 좌표 표시·복사는 원문 정밀도를 유지합니다.
- 맥스배틀은 별도 `battles`/다른 레이어여서 포함하지 않습니다. 현재 레이드 종류·등급·보스 칩으로 선택할 수 있습니다.
- 실제 로비 참가 인원·모집 상태·주변 플레이어 수는 현재 공급원에 없습니다. 레이드 수를 사람 수로 바꾸거나 혼합 점수로 표시하지 않습니다. 이 정보를 제공하는 별도 공급원이 있어야 참여 인원 기반 순위를 연결할 수 있습니다.

공개 모집 서비스도 별도로 확인했습니다. [RaidLobby](https://raidlobby.com/en/find)는 좌표가 없고 `joinedCount`가 친구 코드 복사로 증가하며 현장 인원은 호스트 입력입니다. [PokeLobby](https://pokelobby.com/go)의 회원 수는 사이트 모집방 인원이고 좌표가 없습니다. [RaidNow](https://raidnow.leekduck.com/)의 신청/준비 인원·국가는 체육관 위치나 게임 내 실시간 인원과 다릅니다. 이 값들은 지역별 실제 참여 인원 순위에 합산하지 않았습니다.

## 추가로 조사한 지도

- [공식 지도](https://pokemongo.com/map): Pokémon GO 로그인 필요. 현재 연동 가능한 공개 참여 인원 API는 확인하지 못했습니다.
- [Minpoke](https://9db.jp/pokemongo/map): 공개 지도와 조회 방식을 확인했으나 조사한 도쿄 응답에 실시간 레코드가 없어 보조 수집기로 연결하지 않았습니다.
- [PokeXperience](https://pokexperience.com/raids/): 공개 페이지의 데이터 요청을 확인했으나 외부 요청은 origin 오류였습니다. 연결하지 않았습니다.
- [PokeHunter](https://pokehunter.co/): 현재 페이지가 Campfire 이용을 안내해 수집기로 연결하지 않았습니다.
- [PoGoMapper](https://pogomapper.com/coverage-map): 전날 수집 범위 통계로, 현재 체육관 레이드 공급원과 구분했습니다.
- 국내 [RocketMap](https://rocketmap.kr/)은 조사 시 레이드 로테이션 자료이며 현재 체육관 좌표는 제공하지 않았습니다. 과거 서울 지도 도메인은 광고 도메인으로 전환돼 제외했습니다.
- 기타 유럽 지도에서 확인한 익명 사용 권한과 실제 공개 결과를 구분했습니다. 로그인한 데이터가 필요한 경우에는 연결하지 않았습니다.

## 실행 한도

도시별60초 캐시, 실패30초 대기, 동시 호출 합치기를 사용합니다. 근처 조회는 최대6개 병렬·개별4초·전체10초 제한, 응답2MiB·800개 제한입니다. 지역 지도는8초·8MiB·5000개 제한입니다. 합친 입력의 검증 한도는50000개로, 현재 최대44200개보다 큽니다. 각 레이드의 유효기간과 종료5분 조건은 개별 적용합니다.

일부 도시가 오래됐다는 이유로 전체를 오래된 피드로 만들지 않습니다. 합친 피드에는 최신 정상 원문 시각을 사용하되 개별 레이드의 원문 시각·만료를 보존하며 오래된 도시 상태는 따로 표시합니다. 자료 수가 바뀌지 않아도 새 개별 관측 시각을 만들어 내지 않습니다.
